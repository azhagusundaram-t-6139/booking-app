Day 03 Go Session

Today's lesson is pretty exciting, I have learned below items today. 
1. Organize / splitting the code in multiple files in the same package
2. Creating different packages and referring them another package; in the import statement we should give, "module/packagename" if the package is non-inbuilt package. 
3. 3 level of variables - local, package, global
4. if one package's func or var is accessed in another package, we should export them. We shall export them just by making the first letter to capital letter.
5. A New datatype - `map` => used for storing "key : value" 
6. there is a datatype restriction in map. all the keys should be in same datatype. same for values as well. So, you cannot have string datatype value for first key and int for the second.
7. A New datatype - `struct`=> user defined type; we shall put different datatype properties into a struct and make it as a datatype. Much cleaner approach to store user data. 
8. string covertion - `strconv` package is used
